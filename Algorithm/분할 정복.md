# 분할 정복 
문제를 더 이상 분할할 수 없을 때까지 동일한 유형의 여러 하위 문제로 나누어 해결하는 방법.
- **분할** | 문제를 2개 이상의 문제로 분할.
- **정복** | 분할이 가능하면 다시 수행하고, 아니면 정복한다. 실시
- **결합** | 정복한 문제들을 통합하여 답을 얻다!

<br>

### 병합 정렬(Merge Sort)

> 시간 복잡도: O(nlogn)

1. 정렬할 데이터 집합의 크기가 0 또는 1이면 이미 정렬된 것.
2. 아닐 경우 데이터 집합을 반으로 나눈다. 이것을 반복.
3. 각 데이터 집합에서 정렬 수행.
4. 데이터 집합이 하나가 될 때까지 병합한다. 병합 과정에서도 정렬 수행
